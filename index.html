Sobre mí

Soy Desarrollador Web enfocado en crear interfaces web accesibles, responsivas y atractivas sin comprometer la lógica del código. Me especializo en transformar requerimientos complejos e ideas de Figma en aplicaciones funcionales, estructuradas en JavaScript y bases de datos relacionales.

Mi enfoque de trabajo prioriza la planificación detallada, la comunicación transparente en equipo y la búsqueda de soluciones predecibles ante imprevistos técnicos — antes de escribir código, planifico la estructura como quien traza un plano.

JavaScript SQL Figma HTML5 semántico Accesibilidad (A11y) CSS responsivo

<section aria-label="que-hago">

Qué hago

Tres territorios donde combino diseño, lógica y comunicación para entregar productos web predecibles y accesibles.

01 — a11y

Accesibilidad & Usabilidad Web

Construyo interfaces responsivas pensadas para todas las personas: navegación por teclado, contraste correcto, HTML semántico y JavaScript nativo que no depende de mouse ni de suposiciones.

02 — data

Lógica & Integridad de Datos

Diseño estructuras de datos y bases de datos relacionales en SQL que sostienen la interfaz, cuidando que la lógica de negocio y el flujo de datos sean consistentes de punta a punta.

03 — team

Metodología & Trabajo en Equipo

Planifico antes de picar código: de Figma a componentes, con comunicación transparente que hace las entregas predecibles y reduce sorpresas de último momento.
